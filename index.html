🎯 遊戲目標 Objective

在有限的預算內，透過盲拍競標各種神秘物品來賺取最高分數！
Score the most points by blind-bidding on mysterious items within a limited budget!

📜 遊戲流程 How to Play
1. 每回合隨機出現一件物品，你只能看到名稱和提示
A random item appears each round — you only see its name & hint
2. 在倒數時間內輸入出價（盲拍＝看不到別人出價）
Place your bid before time runs out (blind = you can't see others' bids)
3. 時間到後揭曉真實價值，出價最高且≤預算者得標
True value is revealed — highest bid within budget wins
4. 得標者分數 ＝ 真實價值 − 出價（買貴會扣分！）
Winner's score = True Value − Bid (overpaying = negative!)
5. 預算會扣除出價金額，歸零後只能觀戰
Your budget decreases by your bid; zero budget = spectator mode
🃏 卡牌介紹 Cards
🔮 偷看 Peek × 1
窺探物品真實價值的大約區間（±5）
Reveals the item's approximate value range (±5)
💸 加稅 Tax × 1
若得標需額外支付出價的 20%（心理戰用）
If you win, pay 20% extra (use as a bluff!)
🛡️ 護盾 Shield × 1
得標且分數為負時，抵消為 0
Negates negative score if you overpay
💡 小技巧 Tips
• 不一定要每回合都出價，保留預算也是策略！
Skipping rounds to save budget is a valid strategy!
• 出價 0 等於棄權 / Bidding 0 = pass (no cost)
• 同出價時先出價者優先 / Ties: earlier bid wins
• 善用卡牌扭轉局勢！ Use cards wisely!
